# Terra3D - 3D World Map & Real City Walk Explorer 🌍

> **Live Website:** [https://mshamil070806-ai.github.io/terra3d/](https://mshamil070806-ai.github.io/terra3d/)

ഒരു സമ്പൂർണ്ണ 3D വേൾഡ് മാപ്പ് വെബ് ആപ്ലിക്കേഷൻ. ഇതിൽ ലോകത്തെ മുഴുവൻ യഥാർത്ഥ 3D രൂപത്തിൽ കാണാനും, സാറ്റലൈറ്റ് 3D ടെറൈനിലൂടെ താഴെ ഇറങ്ങി നടക്കാനും (Walk Mode), 3D നഗരങ്ങൾ കാണാനുമുള്ള സൗകര്യങ്ങൾ ഉൾപ്പെടുത്തിയിരിക്കുന്നു.

---

## 🌟 പ്രധാന സവിശേഷതകൾ (Key Features)

### 1. 🌐 3D സിനിമാറ്റിക് ഗ്ലോബ് (Three.js Space Globe)
* **3D ടോപ്പോളജി & ബംപ് റിലീഫ്:** എവറസ്റ്റ്, ആൽപ്സ്, ആൻഡീസ് തുടങ്ങിയ പർവതനിരകൾ യഥാർത്ഥ 3D ഉയരത്തിൽ കാണാം.
* **തത്സമയ അന്തരീക്ഷവും മേഘങ്ങളും:** ഭൂമിയെ വലംവെക്കുന്ന യഥാർത്ഥ മേഘങ്ങളുടെ ആനിമേഷൻ ലെയർ.
* **ഡേ & നൈറ്റ് മോഡ്:** രാത്രിയിൽ നഗരങ്ങൾ പ്രകാശിക്കുന്ന മാന്ത്രിക കാഴ്ച.
* **അന്താരാഷ്ട്ര ഫ്ലൈറ്റ് റൂട്ടുകൾ (3D Arcs):** ലോകത്തിലെ പ്രധാന നഗരങ്ങളെ ബന്ധിപ്പിക്കുന്ന പ്രകാശമാനമായ ഫ്ലൈറ്റ് പാതകൾ.

### 2. 🏔️ സാറ്റലൈറ്റ് 3D വാക്ക് (MapLibre GL GIS Streaming)
* **യഥാർത്ഥ സാറ്റലൈറ്റ് ഇമേജറി:** High-Resolution ArcGIS Satellite Imagery.
* **3D ടെറൈൻ എലവേഷൻ (DEM):** AWS Terrarium DEM ഉപയോഗിച്ച് ലോകത്തിലെ എല്ലാ മലനിരകളും 3D യിൽ ഉയർന്നുനിൽക്കുന്നു.
* **ഗ്രൗണ്ട് ലെവൽ ഐ-വ്യൂ:** 80°-85° ക്യാമറ ആംഗിളിൽ നിലത്തുനിന്നുകൊണ്ട് മുന്നിലേക്ക് നോക്കാം.
* **നടക്കാനുള്ള കൺട്രോളുകൾ:** <kbd>W</kbd>, <kbd>A</kbd>, <kbd>S</kbd>, <kbd>D</kbd> അല്ലെങ്കിൽ Arrow keys വഴി ഭൂപ്രകൃതിയിലൂടെ നേരിട്ട് നടക്കാം.

### 3. 🏙️ 3D സിറ്റി & ടെറൈൻ മെഷ് (BlenderGIS & MapsModels Inspired)
* **വെനീസ് 3D സിറ്റി:** കനാലുകളും (Water), കൽപാലങ്ങളും (Stone Bridges), ഇറ്റാലിയൻ കെട്ടിടങ്ങളും.
* **മാൻഹാട്ടൻ ന്യൂയോർക്ക്:** അംബരചുംബികളായ 3D കെട്ടിടങ്ങളും തെരുവുകളും.
* **ഹിമാലയൻ 3D പർവതനിരകൾ:** യഥാർത്ഥ ഉയരത്തിലുള്ള 3D ടെറൈൻ മെഷ്.
* **മൂന്നാർ & പശ്ചിമഘട്ടം:** കേരളത്തിലെ കുന്നിൻനിരകൾ.

## 🎮 കൺട്രോളുകൾ (How to Control)

| കീ | പ്രവർത്തനം |
| :--- | :--- |
| <kbd>W</kbd> / <kbd>↑</kbd> | മുന്നോട്ട് നടക്കുക (Walk Forward) |
| <kbd>S</kbd> / <kbd>↓</kbd> | പിന്നോട്ട് നടക്കുക (Walk Backward) |
| <kbd>A</kbd> / <kbd>←</kbd> | ഇടത്തോട്ട് നടക്കുക (Walk Left) |
| <kbd>D</kbd> / <kbd>→</kbd> | വലത്തോട്ട് നടക്കുക (Walk Right) |
| <kbd>Shift</kbd> | വേഗത്തിൽ ഓടുക (Sprint) |
| <kbd>Space</kbd> | ചാടുക (Jump) |
| **Mouse Right Click + Drag** | 360° ചുറ്റും നോക്കുക (Look Around) |

## 🚀 ലോക്കലായി റൺ ചെയ്യാൻ (Local Setup)

1. ഫയലുകൾ ഡൗൺലോഡ് ചെയ്യുക അല്ലെങ്കിൽ ക്ലോൺ ചെയ്യുക:
   ```bash
   git clone https://github.com/mshamil070806-ai/terra3d.git
   cd terra3d
   ```
2. `launch.bat` ഡബിൾ ക്ലിക്ക് ചെയ്യുക (അല്ലെങ്കിൽ `node server.js` റൺ ചെയ്ത് `http://localhost:5500/` തുറക്കുക).
